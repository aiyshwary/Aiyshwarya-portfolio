# Portfolio (scaffold)

This repository contains a static portfolio scaffold that automatically populated project cards from the detailed project explanations in `Project_Explanation_Detailed copy/`.

How to run locally:

1. Install dependencies (virtualenv already configured for this workspace).
2. Start a local dev server:

   ```bash
   python -m http.server 5500
   ```

3. Open http://localhost:5500 in your browser.

What I added:
- `index.html`, `styles.css`, `script.js` — responsive single-page portfolio UI

- `assets/images/*` — autogenerated SVG thumbnails for each project
- `assets/resume.pdf` — copy of your resume
- `projects.json` — extracted summaries enhanced into `impact`, `bullets`, `techs`, and `thumbnail` fields used by the UI
